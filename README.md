# PromptBlocks

Кастомные ноды для ComfyUI, которые помогают собирать промпт для видео-модели **MiniMax H3 (Hailuo 3.0)**, не вспоминая каждый раз, как правильно оформить текст.

## Зачем это вообще нужно

У MiniMax H3 довольно строгий формат промпта — если писать его вручную одним текстовым полем, легко забыть нужную часть, перепутать порядок или неправильно сослаться на референс. PromptBlocks решает это так: ты собираешь промпт из готовых блоков через меню (кликами, без ручного набора формата), а нода сама превращает это в текст, который модель понимает правильно.

Работает для **любого формата MiniMax H3**, какой тебе нужен в моменте:
- обычный текст-в-видео (просто стиль + шот, без картинок),
- первый кадр (image-to-video),
- последний кадр (last-frame-to-video),
- первый и последний кадр сразу (две картинки),
- референс-к-видео (Ref2VA) — с картинками и/или видео-референсами, персонажами, одеждой, позами и т.д.

Какой блок референса добавишь — тот формат и получится в промпте. Ничего не зашито жёстко под один режим.

Два узла в комплекте:

- **Prompt Blocks** — основной конструктор промпта.
- **Scene Builder** — отдельный конструктор персонажа (внешность, одежда, поза), результат которого можно вставить в Prompt Blocks как готовое описание.

## Установка

1. Склонировать в `ComfyUI/custom_nodes/`:
   ```bash
   git clone https://github.com/designer-trifonov/MinimaxPrompBuilder.git PromptBlocks
   ```
2. Перезапустить ComfyUI. Узлы появятся в категории **MiniMax H3**.

## Что внутри Prompt Blocks

**Референсы** — картинка (`<Picture N>`) или видео (`<Video N>`), с выбором, что на референсе (человек, одежда, предмет, помещение, движение, стиль...) и что с этим делать (сохранить полностью, взять только черты, перенести на другого и т.д.).

**Шот** — сюда добавляются:
- Персонаж (вручную или сразу «с референса №N»),
- Образ (одежда на персонаже),
- Связь референсов (готовые фразы вида «А одет в одежду с B»),
- План кадра (крупный/средний/общий план и т.п.),
- Описание кадра — готовые целые фразы-кадры, свои шаблоны,
- Камера, Действие (можно отдельно — действие персонажа и действие «за кадром»), Диалог.

**Шаблоны.** Всё, что можно сохранить (стиль, кадры, звуки, реплики, позы в Scene Builder), хранится в JSON-файлах и редактируется прямо из интерфейса — выбрал, поправил, сохранил как свой вариант. Отдельная кнопка «📋 Шаблон» сохраняет и загружает вообще весь набор блоков ноды одним пресетом.

## Твои шаблоны

Сохранённые шаблоны (стили, кадры, звуки, диалоги, позы, персонажи) лежат не в этом репозитории, а в `ComfyUI/user/<профиль>/PromptBlocks/*.json` — это твои личные данные.

В папке `examples/` — стартовый набор для тех, кто только поставил ноду и видит пустые списки: визуальный стиль, план кадра, камера, звуки/фон, связь референсов, диалог, музыка, и атрибуты Scene Builder (телосложение, рост, глаза, цвет/стиль волос, кожа, цвета, одежда по категориям). Скопируй нужные файлы в свою `user/<профиль>/PromptBlocks/` папку.

Чего в `examples/` нет и не будет: готовых сохранённых персонажей, поз и «описаний кадра»/«действий» — эти категории в личной сборке автора содержат 18+ контент, который не для публичного репозитория.

## Структура кода

```
__init__.py           — регистрация нод
scene_builder.py       — нода Scene Builder (Python-сторона)
js/promptBlocks.js     — точка входа Prompt Blocks
js/sceneBuilder.js     — точка входа Scene Builder
js/blocks/             — блоки верхнего уровня (референс, стиль, шот, звук, музыка)
js/items/               — элементы внутри шота (персонаж, поза, действие, камера, диалог...)
js/scene/               — логика Scene Builder (атрибуты, одежда, правила по возрасту)
js/lib/                 — общие DOM-хелперы, меню, хранилища шаблонов
js/core/                — компиляция промпта, реестр хранилищ
examples/                — безопасные примеры пользовательских шаблонов
```
