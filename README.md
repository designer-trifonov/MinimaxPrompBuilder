# PromptBlocks

Кастомные ноды для ComfyUI, собирающие структурированный промпт под **MiniMax H3 (Hailuo 3.0)** — режим reference-to-video (Ref2VA). Вместо одного текстового поля — конструктор из блоков: референсы (картинка/видео), визуальный стиль, шоты с камерой/позой/действиями/диалогом, звук и музыка. Результат собирается в официальный формат `subject_definitions` / `retention_analysis` / шоты автоматически.

Два узла в комплекте:

- **Prompt Blocks** — основной конструктор промпта (референсы, стиль, шоты, звук, музыка).
- **Scene Builder** — отдельный конструктор персонажа (внешность, одежда, поза) как текстовый блок, который можно переиспользовать в Prompt Blocks.

## Установка

1. Склонировать в `ComfyUI/custom_nodes/`:
   ```bash
   git clone https://github.com/designer-trifonov/MinimaxPrompBuilder.git PromptBlocks
   ```
2. Перезапустить ComfyUI. Узлы появятся в категории **MiniMax H3**.

## Возможности Prompt Blocks

### 🧩 Референс (reference-to-video)
- Картинка (`<Picture N>`) или видео (`<Video N>`) — отдельные счётчики тегов, общий сквозной `<Subject N>`.
- Роли для картинки: Человек / Одежда / Предмет / Помещение / Другое.
- Роли для видео: Движение / Персонаж / Стиль / Структура сцены.
- Варианты сохранения (retention): `fully_preserved`, `weak_reference`, `partially_preserved`, `attribute_transfer` — с явным анти-двусмысленными формулировками под каждую роль.

### Шот — что можно добавить
- 🧑 **Персонаж** — вручную или мгновенно «с референса №N» (автоматически заводит нужный референс-блок).
- 👗 **Образ** — одежда, применяемая к субъекту.
- 🔗 **Связь референсов** — готовые фразы вида «{A} wears the outfit from {B}».
- 📐 **План кадра** — крупный/средний/общий план и т.д.
- 🎬 **Описание кадра** — готовые полные фразы-кадры (POV и т.п.), в отличие от «Плана кадра» это целиком готовое предложение, а не начало фразы.
- 🎥 **Камера**, **⏱️ Действие** (отдельно для референса и «за кадром»), **💬 Диалог** (сгруппирован по категориям, например «Интонация»).

### Шаблоны
- Каждый список (стиль, кадры, звуки, диалог, позы в Scene Builder) хранится в JSON и редактируется прямо из интерфейса (сохранить/удалить свой вариант).
- Кнопка **«📋 Шаблон»** в Prompt Blocks сохраняет/загружает весь набор блоков ноды целиком, одним пресетом.

## Пользовательские данные

Твои сохранённые шаблоны (стили, кадры, звуки, диалог, позы, персонажи и т.д.) живут отдельно от кода — в `ComfyUI/user/<профиль>/PromptBlocks/*.json`, не в этом репозитории. В `examples/` лежат безобидные примеры (без 18+) для тех, кто хочет быстро наполнить пустые списки при первой установке — скопируй нужные файлы в свою `user/<профиль>/PromptBlocks/` папку вручную.

## Структура кода

```
__init__.py           — регистрация нод
scene_builder.py       — нода Scene Builder (Python-сторона)
js/promptBlocks.js     — точка входа Prompt Blocks
js/sceneBuilder.js     — точка входа Scene Builder
js/blocks/             — блоки верхнего уровня (референс, стиль, шот, звук, музыка)
js/items/               — элементы внутри шота (персонаж, поза, действие, камера, диалог...)
js/scene/               — логика Scene Builder (атрибуты, одежда, правила по возрасту)
js/lib/                 — общие DOM-хелперы, меню, хранилища шаблонов
js/core/                — компиляция промпта, реестр хранилищ
examples/                — безопасные примеры пользовательских шаблонов (без 18+)
```
